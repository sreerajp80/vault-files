# Files explorer view modes: List / Grid (thumbnail) / Compact

Implements plan `plans/20260624_183607_files-view-modes.md`.

## Summary

Added three selectable layouts to the Files explorer — **List** (existing, default),
**Grid / thumbnail**, and **Compact** — switchable via an icon toggle in the section header.
The selected mode is persisted in Room settings (`file_view_mode`) so it survives restarts.

## Changes

- **`app/src/main/java/com/example/data/StorageRepository.kt`**
  - Added `getFileViewModeFlow()`, `getFileViewMode()` (default `"list"`), and
    `saveFileViewMode(mode)`, keyed `"file_view_mode"` (mirrors `storage_source_mode`).

- **`app/src/main/java/com/example/ui/StorageViewModel.kt`**
  - Added `_fileViewMode` / `fileViewMode: StateFlow<String>`, loaded in `init`.
  - Added `updateFileViewMode(mode)` (no-ops when unchanged; saves + updates state, no toast).

- **`app/src/main/java/com/example/ui/FileExplorerScreen.kt`**
  - New `FileViewMode` enum (`LIST` / `GRID` / `COMPACT`) carrying each mode's storage key,
    icon, and content-description string, plus a `fromKey()` resolver.
  - Section header now hosts a compact `ViewModeToggle` segmented control (three mode icons,
    active one highlighted) beside the existing Sort control.
  - Extracted the per-item tap logic into a single shared `handleItemClick` lambda so all three
    layouts behave identically (unlock prompt, navigate, extract, open note, image/text preview,
    fallback message).
  - Content area now branches on the active mode:
    - `LIST` → existing `LazyColumn` of `FileRowItem` (unchanged behaviour).
    - `GRID` → `LazyVerticalGrid` (`Adaptive(104.dp)`) of new `FileGridItem` tiles; image files
      show a real Coil thumbnail (`SubcomposeAsyncImage`, category-icon fallback on load/error),
      with APK launcher icons, locked/secured indicators reused, and a corner overflow button.
    - `COMPACT` → `LazyColumn` of new dense `FileCompactRow` (small icon, name, size, overflow).
  - Empty / loading / permission / category-filter states are unchanged (they wrap the branch).

- **`app/src/main/res/values/strings.xml`** and **`values-ml/strings.xml`**
  - Added `cd_view_list`, `cd_view_grid`, `cd_view_compact` (English + Malayalam).

## Notes

- No new dependency: Coil was already used for the full-screen image preview.
- Real thumbnails are images-only; videos and other types show their category icon
  (video-frame thumbnails would need the `coil-video` decoder — out of scope).
- `./gradlew compileDebugKotlin` → BUILD SUCCESSFUL.
