# Added docs/features.md

Implements plan: `plans/20260802_000000_features_doc.md`

## What changed

Added `docs/features.md`, a full inventory of the app's current features, written for
sharing with an AI assistant working on other apps. Covers:

- A short description of what the app is.
- An upfront caveats section making clear what is real security (Secure Notes'
  AES-256-GCM/Keystore encryption) versus what only looks secure (the Vault is unencrypted
  copy+rename+DB tracking; shielded folders are an in-app navigation gate, not encryption;
  PINs are stored in plain text).
- A feature-by-feature list grouped to match the app's own structure: app shell, Storage
  Analyzer tab, File Explorer tab (browsing, search/sort, view modes, file operations,
  previews, secure notes), shielded folders, Vault tab, Secure Notes encryption, Settings
  (Display/Security/Help/Permissions/About), and cross-cutting infrastructure
  (DocumentsProvider/SAF exposure, localization, theming).

No app code was changed — documentation only. Content is based on a full read of
`MainActivity.kt`, `StorageViewModel.kt`, `StorageRepository.kt`, all `ui/*.kt` screens,
`CryptoManager.kt`, `VaultDocumentsProvider.kt`, `DatabaseEntities.kt`,
`AndroidManifest.xml`, and the existing `docs/architecture.md` / `docs/build.md`.
