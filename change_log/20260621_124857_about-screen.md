# Change log: About section in Settings + About screen

Implements plan `plans/20260621_124250_about-screen.md`.

## What changed

### New files
- **`app/about.properties`** — editable config file holding `author`, `ide`, `aiVersion`.
- **`app/src/main/java/com/example/ui/AboutScreen.kt`** — `AboutScreen(onBack, modifier)` composable.
  Shows app name + version, a "Build Information" section with four rows (Author, IDE Used,
  AI Used Version, Last Build Date) read from `BuildConfig`, and a centered
  "Made with ❤ from India" footer (heart via `Icons.Default.Favorite`, red tint). Styled to match
  the rounded `Surface` cards used in `SettingsScreen`. Has a back arrow in the `TopAppBar`.

### Edited files
- **`app/build.gradle.kts`**
  - Added imports `java.text.SimpleDateFormat`, `java.util.Date`.
  - Loads `about.properties` at configuration time (`aboutProps`), with an `aboutValue()` helper that
    quotes/escapes values for `buildConfigField`.
  - Computes `buildDate` (`yyyy-MM-dd HH:mm`) at build time.
  - Adds `BuildConfig` String fields: `AUTHOR`, `IDE`, `AI_VERSION`, `BUILD_DATE`.
- **`app/src/main/java/com/example/ui/SettingsScreen.kt`**
  - Added `showAbout` state; when true, renders `AboutScreen` and returns early (in-Settings
    navigation, since the project has no nav library).
  - Added a tappable "About Vault Files" row (Info icon + chevron, `testTag("about_row")`) at the end
    of the Help & Information section that sets `showAbout = true`.

## Notes
- `BuildConfig` is generated under the build `namespace` package, so `AboutScreen` imports
  `` `in`.sreerajp.vault_files.BuildConfig `` (not `com.example`) — consistent with the namespace
  caveat in CLAUDE.md.
- `ide` value in `about.properties` was adjusted post-build by the user to
  "Android Studio, Visual Studio Code"; no code change needed (read at build time).

## Verification
- `./gradlew assembleDebug` — BUILD SUCCESSFUL (compiles with the new BuildConfig fields and the
  About screen / Settings wiring).
