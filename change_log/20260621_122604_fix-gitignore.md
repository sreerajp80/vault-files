# Change log: Ensure `.gitignore` is proper

Implements plan `plans/20260621_122514_fix-gitignore.md`.

## What changed
Rewrote the root `.gitignore`:

- **Added `*.jks`** — closes the critical gap where the real signing keystore
  `vfkeystore.jks` (private key, used for both debug and release signing in
  `app/build.gradle.kts`) was not ignored and would have been committed.
- **Added `*.keystore`** — catch-all for keystores; replaces the specific `debug.keystore`
  entry (now covered by the wildcard).
- **Removed the duplicate `local.properties` line** — kept `/local.properties`.
- **Added `*.apk` and `*.aab`** — ignore build artifacts as a safety net.
- Grouped secrets and build artifacts under comment headers for clarity.
- Retained all prior entries: `*.iml`, `.gradle`, `.kotlin`, `/local.properties`, `.idea/*`,
  `.DS_Store`, `/build`, `/captures`, `.externalNativeBuild`, `.cxx`, `.env`,
  `keystore.properties`.
