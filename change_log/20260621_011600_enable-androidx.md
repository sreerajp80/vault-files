# Change log: Enable AndroidX in gradle.properties

Implements plan `plans/20260621_011600_enable-androidx.md`.

## What changed

- `gradle.properties` — added `android.useAndroidX=true` (with an explanatory comment),
  immediately after the existing `android.nonTransitiveRClass=true` line.

## Why

Gradle emitted a warning that `:app:debugRuntimeClasspath` contains AndroidX dependencies while
`android.useAndroidX` was not enabled, which may cause runtime issues. All project dependencies
(Compose, Room, biometric, lifecycle, activity, core-ktx, etc.) are AndroidX, so the flag is
required.

## Not changed

- `android.enableJetifier` was intentionally left unset — the project has no legacy
  `com.android.support:*` dependencies, so Jetifier is unnecessary.
- No Kotlin/Java source was modified; this is a build-config-only change.
