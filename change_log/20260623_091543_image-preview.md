# Change log: In-app image preview with a gating setting

Implements [plans/20260623_085025_image-preview.md](../plans/20260623_085025_image-preview.md).

## Summary
Added a full-screen, in-app image preview. Tapping an image file opens it over a dark
scrim; a new **Image Preview** setting (Display & Themes) gates the feature. The preview
attempts to decode anything categorized as an image and degrades to a "Can't preview this
format" state when no decoder is available — rather than a short hardcoded allowlist.

## Files changed
- **gradle/libs.versions.toml** — added `coil-gif` and `coil-svg` library aliases (reusing
  the existing `coilCompose = "2.7.0"` version ref).
- **app/build.gradle.kts** — uncommented `implementation(libs.coil.compose)` and added
  `coil.gif` + `coil.svg`.
- **app/src/main/java/com/example/data/StorageRepository.kt**
  - Broadened the `"Image"` branch in `getCategoryForFile` to include `jpe, jfif, heic,
    heif, avif, ico, tif, tiff` and RAW (`dng, cr2, nef, arw, orf, rw2`) on top of the
    existing `jpg/jpeg/png/gif/webp/bmp/svg`. (Side effect: Storage Analysis now counts
    these as images — a correctness improvement.)
  - Added `getImagePreviewEnabledFlow()`, `isImagePreviewEnabled()` (default `true`), and
    `saveImagePreviewEnabled(enabled)` (key `image_preview_enabled`).
- **app/src/main/java/com/example/ui/StorageViewModel.kt**
  - Added `imagePreviewEnabled` StateFlow (loaded in `init`) and
    `updateImagePreviewEnabled(enabled)` (persists + emits a toast).
  - Added `imagePreview` StateFlow with `openImagePreview(item)` / `closeImagePreview()`.
- **app/src/main/java/com/example/ui/FileExplorerScreen.kt**
  - Collected `imagePreviewEnabled` and `imagePreview`.
  - In `onItemClick`, route taps on `category == "Image"` files to `openImagePreview` when
    the setting is on (otherwise the old "Viewing…" toast).
  - Added a private `ImagePreviewDialog` composable: a full-screen `Dialog` with a custom
    Coil `ImageLoader` registering the animated (ImageDecoder/GifDecoder) and SVG decoders,
    `SubcomposeAsyncImage` with loading spinner and a `BrokenImage` error fallback, plus a
    top bar showing the filename and a close button. Dismiss via scrim tap, close button,
    or system back.
- **app/src/main/java/com/example/ui/SettingsScreen.kt** — added an "Image Preview"
  `SettingsTile` + `Switch` in the Display page (after Show Hidden Items), wired to the VM.
- **app/src/main/res/values/strings.xml** and **values-ml/strings.xml** — added
  `image_preview_title`, `image_preview_subtitle`, `cd_close_preview`,
  `image_preview_error`, `msg_image_preview_enabled`, `msg_image_preview_disabled`
  (English + Malayalam).

## Verification
- `./gradlew assembleDebug` succeeded; `app-debug.apk` produced.
- Not yet manually exercised on a device/emulator.

## Notes
- Local `File` decode only — no network or new manifest permissions.
- No pinch-zoom in this pass (image fits the screen).
- RAW/TIFF/PSD/JXL are attempted but may hit the graceful fallback (no platform decoder);
  a dedicated decoder library was intentionally left out of scope.
