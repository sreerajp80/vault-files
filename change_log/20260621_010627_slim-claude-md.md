# Change log: Slim down CLAUDE.md by offloading detail to on-demand docs

Implements plan `plans/20260621_010627_slim-claude-md.md`.

## What changed

- **`CLAUDE.md`** rewritten from ~110 lines down to ~40. Retained only the always-relevant
  facts: the overview + "simulated data / no live AI" warning, the namespace caveat (3 IDs), the
  core build/single-test commands, a one-paragraph architecture summary, and a pointer index to
  the new docs. Mandated `# CLAUDE.md` header preserved.

- **`docs/build.md`** (new) — moved the full build/test detail out of CLAUDE.md: Roborazzi
  screenshot tasks, lint, `connectedAndroidTest`, signing gotchas (`debugConfig` keystore, release
  env vars), secrets plugin / `.env`, config-cache notes, SDK/JVM versions, and the namespace caveat.

- **`docs/architecture.md`** (new) — moved the full layer-by-layer architecture breakdown
  (MainActivity, StorageViewModel, StorageRepository, Room, utils) and the "conventions worth
  following" section (adding a preference, action→repo→message→refresh flow, testTag convention,
  session-based unlock model).

## Effect

Per-session baseline context is reduced to the essentials; deeper build and architecture detail is
now one `Read` away via the pointers in CLAUDE.md, loaded only when a task needs it.

## Not changed

No source (`.kt`), Gradle, or manifest files were touched — documentation only.
