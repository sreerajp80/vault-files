# Plan: Add an About section in Settings + About screen

## What the user wants
- In **Settings**, add an **About** section/row. Tapping it opens an **About screen**.
- The About screen shows, sourced **from a config file**:
  - Author
  - IDE used
  - AI Used Version
  - Last Build date
- Also display **"Made with ❤ from India"** on the About screen.

## Current state / constraints
- No navigation library (`androidx.navigation.compose` is commented out in `app/build.gradle.kts`).
  `MainActivity` swaps tab content by integer index; each tab is a single composable.
  So in-Settings navigation to About will be done with internal Compose state
  (`var showAbout by remember { mutableStateOf(false) }`) swapping content via `AnimatedContent`
  (the `androidx.compose.animation.*` wildcard is already imported in `SettingsScreen.kt`).
- `buildConfig = true` is already enabled in `app/build.gradle.kts`, so `BuildConfig` fields are the
  natural, idiomatic carrier for the config values. The build module already reads a `.properties`
  file (`keystore.properties`) in the build script, so the same pattern fits here.

## Approach (the "config file")
Create a plain config file `app/about.properties` (project app-module root, alongside
`build.gradle.kts`) holding the static, human-editable values:

```
author=Sreeraj P
ide=Android Studio
aiVersion=Claude Opus 4.8
```

`app/build.gradle.kts` reads this file at configuration time and exposes the values plus a generated
build date as `BuildConfig` String fields:
- `BuildConfig.AUTHOR`
- `BuildConfig.IDE`
- `BuildConfig.AI_VERSION`
- `BuildConfig.BUILD_DATE`  — generated at build time (`SimpleDateFormat` of `Date()`), since
  "Last Build date" is inherently dynamic and cannot be a static file entry.

This keeps the author/IDE/AI-version values in an editable config file while the build date is stamped
each build. (Exact default values for author/IDE/AI version to be confirmed — see Open question.)

## Files to change
1. **`app/about.properties`** (new) — config file with `author`, `ide`, `aiVersion`.
2. **`app/build.gradle.kts`** (edit) — load `about.properties`; add `buildConfigField` entries for
   `AUTHOR`, `IDE`, `AI_VERSION`, and a generated `BUILD_DATE`. (Imports `java.util.Properties` already
   present; add `java.text.SimpleDateFormat` / `java.util.Date` as needed.)
3. **`app/src/main/java/com/example/ui/AboutScreen.kt`** (new) — `AboutScreen(onBack: () -> Unit)`
   composable: `TopAppBar` with a back arrow, info rows (Author / IDE / AI Version / Last Build date)
   reading from `BuildConfig`, and a centered "Made with ❤ from India" footer (heart shown via
   `Icons.Default.Favorite` tinted red, or the ❤ glyph). Styled to match the existing rounded
   `Surface` cards used in `SettingsScreen`.
4. **`app/src/main/java/com/example/ui/SettingsScreen.kt`** (edit) —
   - Add `var showAbout by remember { mutableStateOf(false) }`.
   - Wrap current Settings content vs. `AboutScreen` in `AnimatedContent` (or simple `if/else`),
     passing `onBack = { showAbout = false }`.
   - Add a new "About" `Text` section header + a tappable `Surface` row (Info icon + "About Vault
     Files" + chevron) under Help & Information that sets `showAbout = true`. Include a `testTag`
     (e.g. `about_row` / `about_screen`) to match the project's testTag convention.

## Out of scope
- No new dependencies, no nav library, no changes to `MainActivity` tab structure.
- Real build metadata beyond date (e.g. git hash) not included unless requested.

## Verification
- `./gradlew assembleDebug` builds (confirms BuildConfig fields + properties read).
- Manual: Settings → tap About → screen shows the four fields and the "Made with ❤ from India" line;
  back arrow returns to Settings.
