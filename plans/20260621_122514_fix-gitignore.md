# Plan: Ensure `.gitignore` is proper

## Issue

Audit of the root `.gitignore` against the files actually present in the repo found one
**critical** secret-leak gap plus a few hygiene issues.

### Critical
- **`vfkeystore.jks` is NOT ignored.** This is the real signing keystore (private key) used
  for *both* debug and release builds (`app/build.gradle.kts:36,42`). It currently sits at the
  project root and would be committed. The `.gitignore` only lists `debug.keystore`, which does
  not match `vfkeystore.jks`.
- `keystore.properties` (real store/key passwords, lines 3-6) *is* already ignored — good — but
  the keystore file it references is not.

### Hygiene
- `local.properties` is listed twice (line 4 `/local.properties` and line 16 `local.properties`).
- No catch-all for keystores (`*.jks`, `*.keystore`) — only the specific `debug.keystore`.
- No ignore for build output artifacts (`*.apk`, `*.aab`) — minor, since `/build` is ignored.

## Files to change
- `l:\Android\vault-files\.gitignore` (root)

(No changes needed to `app/.gitignore`, `.idea/.gitignore`, or `assets/.aistudio/.gitignore` —
those are correct as-is.)

## Fix

Update the root `.gitignore` to:
1. Add `*.jks` and `*.keystore` (covers `vfkeystore.jks`, `debug.keystore`, and any future
   keystore). Keep an explicit `debug.keystore` is then redundant but harmless — will remove it
   since `*.keystore` covers it.
2. Remove the duplicate `local.properties` line.
3. Add `*.apk` and `*.aab` for safety.
4. Keep `keystore.properties`, `.env`, `.gradle`, `.kotlin`, `/build`, `/captures`, IDE entries.

## Note (outside this change)
`vfkeystore.jks` and the real passwords in `keystore.properties` already exist on disk. This
project reports `Is a git repository: false`, so nothing has been committed yet — adding the
ignore now is sufficient and no history scrub is needed. If a git repo is later initialized,
these files will be correctly excluded.
